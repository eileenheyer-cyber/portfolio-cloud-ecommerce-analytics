E-Commerce Cloud-Architektur — Batch-Only-Konzept

Überarbeitete Fassung: Streaming-Pfad entfernt, Azure SQL Database (serverless) statt PostgreSQL/Fabric, durchgängiges Monitoring. Ausgelegt auf ein monatliches Budget von rund 10 €.

Entfernt

Streaming-Pfad

Event Hubs + Stream Analytics gestrichen: kein belegter Echtzeit-Bedarf, und allein dieser Pfad hätte das 10-€-Budget um ein Vielfaches gesprengt.

Geändert

Azure SQL DB serverless

Ersetzt Azure PostgreSQL: pausiert automatisch bei Inaktivität, sodass nur bei tatsächlicher Nutzung Compute-Kosten anfallen.

Ergänzt

Monitoring-Abdeckung

Azure Monitor überwacht jetzt Functions, Data Factory und die Datenbank statt nur eine Komponente.
